酒馆工具 · 使用说明
════════════════════════════════════════

用原版酒馆（装成酒馆插件）的话用一键安装器（installer/），不需要它。详见 docs/使用指南.md。

双击 launcher\windows\酒馆工具.bat 打开菜单（Termux 用 termux/claude-max.sh）。
按键直接执行，不用回车；也可以 ↑↓ 选、回车执行。子页面里 0 或 Esc 返回，h 看这份说明，q 退出（退出才会关窗口）。
最上面几行回答「现在该干嘛」：
  第一行 ● 可以玩（绿）/ 可以玩但有提醒（黄）/ 还不能玩（红），后面是代理版本、后端（订阅 / API 密钥）、登录；
  第二行「下一步」：一句话告诉你接下来做什么（没登录就按字母登录，都好了就去酒馆里点「一键连接」）；
  有问题时下面一条一个，前面有字母，按它就去修；
  再下面是酒馆在不在运行。
回车 = 推荐操作：代理没开时是「启动代理」，开着时是「打开酒馆」（没配酒馆时是「打开 TT」）。

首页：回车 启动 / 打开    1 重启代理    2 检查状态    3 更多 >
      （config.local 里让酒馆一起启动时，1 是「重启代理和酒馆」）
更多 >：登录 Claude、修复依赖、打开日志、开机自动启动、关闭代理

下面按功能说明（括号里是菜单位置）。

日常
  启动（首页 回车）
                  自检 → 启动代理（和酒馆）→ 打开浏览器；config.local 里 ST_AUTOSTART=0 时
                  只启动代理。已经在运行的会跳过。
  关闭代理（更多）
                  关闭酒馆和代理，聊天记录都已保存。
  重启代理（首页 1）
                  先自检，再关、再开。更新了代码、改了设置、对话一直失败时用。
                  自检不过时会先问你；答 N 就什么都不动。
  检查状态（首页 2）
                  体检：不启动也不关闭任何程序（只有缺依赖时会问要不要装）。
                  遇到问题先用它，看标 ✗ / ! 的项目和「解决办法」。

账号和维护（更多）
  登录 Claude（更多）
                  登录 Claude 订阅账号，一般只需要一次。
  修复依赖（更多）
                  提示「缺少依赖 / Cannot find module」时重装程序库，不动聊天记录。
  打开日志（更多）
                  proxy.log 每轮一行：耗时、缓存读写、输出；出错时附上最后几十行求助。
  开机自动启动（更多）
                  开 / 关。开启的那一刻也会马上在后台启动一次（已经在运行的跳过）。

代理还在跑旧版本时（更新了代码没重启），第一行下面会提示，按对应字母就重启。

符号：✓ 正常   ! 提醒   ✗ 错误（下面有「解决办法」）

常见问题
  发消息报错 / 没反应：先「检查状态」；登录失效就「登录 Claude」。
  端口被占用：窗口里写了是哪个程序，关掉它或重启电脑。
  CCST 面板状态点红色：代理没运行，「启动代理」；黄色：没登录。
  更新扩展后不生效：「重启代理」，再刷新浏览器页面。
  「检查状态」提示代理还是旧版本：没在生成回复时「重启代理」。
  在菜单窗口里按 Ctrl-C 不会关掉已经启动的代理和酒馆（它们在后台单独运行）；要关用「关闭代理」。
