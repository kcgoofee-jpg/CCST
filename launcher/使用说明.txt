【这份工具属于「用法二」：TauriTavern / 手机。】电脑上独立运行代理（手机模式），TauriTavern 装面板后连这台电脑。
用原版酒馆（用法一）的话用一键安装器（installer/），不需要它。详见 docs/使用指南.md。

第一次用：在「终端」里粘贴 README / 使用指南里的那一行安装命令（或双击 launcher/mac/首次安装.command）。
它会装依赖、打开浏览器让你登录 Claude、在桌面放「酒馆工具」，然后直接进下面这个菜单，窗口不会自己关。
提示「无法验证开发者」时：macOS 15 以上，系统设置 → 隐私与安全性 → 拉到底点「仍要打开」；更老的 macOS：在文件上右键 → 打开。

双击桌面的「酒馆工具」打开菜单（Windows：launcher\windows\酒馆工具.bat）。
按键直接执行，不用回车；也可以 ↑↓ 选、回车执行。子页面里 0 或 Esc 返回，h 看这份说明，q 退出（退出才会关窗口）。
最上面几行回答「现在该干嘛」：
  第一行 ● 可以玩（绿）/ 可以玩但有提醒（黄）/ 还不能玩（红），后面是代理版本、后端（订阅 / API 密钥…）、登录；
  第二行「下一步」：一句话告诉你接下来做什么（没登录就按字母登录，都好了就去 TauriTavern 里点「一键连接」）；
  有问题时下面一条一个，前面有字母，按它就去修；
  再下面是酒馆在不在运行；Mac 上还有一行「手机」：开没开。
回车 = 推荐操作：代理没开时是「启动代理」，开着时是「打开 TT」（没配 TT 时是「打开酒馆」）。

首页：回车 启动 / 打开    1 手机    2 重启代理    3 检查状态    4 更多 >
      （config.local 里让酒馆一起启动时，2 是「重启代理和酒馆」）
手机页（首页 1，只支持 Mac）：显示手机模式开没开、手机连接码、二维码；
      c 复制连接码    x 开启 / 关闭手机模式    s 同步手机    l 合盖不睡    回车 / 0 返回
更多 >：账号和维护：登录 Claude、修复依赖、打开日志、开机自动启动、关闭代理
        手机上的 TauriTavern：TT 守护 >、合盖不睡
        其他：生图 >（本机装了 ComfyUI 才有）、本机TT导入（测试用，有可导入的才出现）、柏宝绘配方导入、提示词拆分
  TT 守护 >：1 看状态  2 立即拉一次备份  3 电脑自动拉备份（开 / 关）  4 从备份恢复
Windows 上手机、TT 守护和几个导入工具显示「只支持 Mac」。

下面按功能说明（括号里是菜单位置）。

日常
  启动（首页 回车）
                  自检 → 启动代理（和酒馆）→ 打开浏览器；config.local 里 ST_AUTOSTART=0 时
                  只启动代理、打开 TauriTavern。已经在运行的会跳过。
  关闭代理（更多）
                  关闭酒馆和代理（手机模式的守护一起停），聊天记录都已保存。
                  代理正在写回复时会先问你（关掉会掐断那条回复）。
  重启代理（首页 2）
                  先自检，再关、再开。更新了代码、改了设置、对话一直失败时用。
                  自检不过、或代理正在写回复时会先问你；答 N 就什么都不动。
  检查状态（首页 3）
                  体检：不启动也不关闭任何程序（只有缺依赖时会问要不要装）。
                  遇到问题先用它，看标 ✗ / ! 的项目和「解决办法」。
                  Mac 上还看手机 TT 和 TT 守护，以及第三方扩展的分支有没有设上游
                  （没设的话 TT 查扩展更新会报错；你答 y 才设，只改 .git/config）。

手机（首页 1）
  手机模式（首页 1 > x）
                  开启 / 关闭手机模式。手机模式下：
                  · 同一 Wi-Fi 的手机 TauriTavern 带访问密码用这台 Mac 的代理；
                  · Mac 不空闲睡眠；装了「合盖不睡」（首页 1 > l）合盖也不睡；
                  · 代理掉了 30 秒内自动重启；Mac 断网、换了地址时发通知
                    （Mac 通知中心 + 插着线或开了无线调试的手机）。
                  关闭手机模式：代理只给本机用，Mac 正常睡眠。不要在公共 Wi-Fi 开。
                  切换时代理要重启才生效；它正在写回复就先不重启：
                  · 开启手机模式：守护等代理空闲了自动重启，之后手机就能连；
                  · 关闭手机模式：重启前带访问密码的手机仍能连，写完后选「重启代理」。
                  「检查状态」会提示模式和代理实际监听的不一致。
  同步手机（首页 1 > s）
                  同步中心 ↔ 手机 TauriTavern 双向同步：聊天、角色卡、世界书、预设、
                  头像、背景、生图图片、主题、快速回复、角色卡标签；扩展只从电脑推到手机，
                  换下来的旧扩展文件夹收进存档（手机 data/_cm_archive，每个扩展只留最新一份）。
                  从不删文件；被覆盖的旧文件先存进 backups。
                  步骤：
                  ① 看两边：TT 开没开、在不在生成回复、代理忙不忙；手机上 TT 守护正在恢复备份就不同步。
                  ② 预览，分三组——
                     自动：只有一边改过的，直接做；
                     要你选：两边都改过的聊天（Mac 的 / 手机的 / 两份都留）、别的文件、
                             API 和预设设置（Mac / 手机 / 跳过，连哪个地址各自保留）、
                             API 密钥（两边互补：只加缺的、不启用，正在用的不变 / 跳过）、
                             扩展没设上游、上次恢复没做完、要关正在用的 TT（现在关 / 等生成完 / 取消）；
                     跳过：判断不了的，列出来不动。
                  ③ 你选（直接回车 = 默认，q 取消，取消就什么都不改）。
                  ④ 写手机前让 TT 守护先存一份快照（没装就跳过）。
                  ⑤ 同步，再比一遍两边，列出结果；原来开着的 TT 重新打开。
                  同步中心：config.local 里 SYNC_HUB=tt 是这台 Mac 的 TauriTavern（扩展代码先更新到
                  Mac TT）；SYNC_HUB=st 是电脑酒馆。不写时有酒馆就用酒馆。
                  顺便把手机上的代理地址对准 Mac 现在的 IP；手机模式开着时，手机「自定义」来源
                  正在用的密钥设成 Mac 的访问密码。
                  手机要插 USB 线（开 USB 调试），第一次顺手开「无线调试」，以后同一 Wi-Fi
                  不插线也能同步（手机重启后要插线再开一次）。需要 root。
                  手机上 CCST 面板里的「同步手机」不问问题：两边都改过的用较新的、另一份进备份，
                  API 设置和密钥不动；TT 守护在恢复或上次恢复没做完时不同步。

  合盖不睡（首页 1 > l）
                  装 / 卸（装的时候输一次 Mac 登录密码）。装好后手机模式下合上盖子
                  Mac 也不睡，继续给手机提供代理。自动放开、合盖就睡的情况：
                  · 用电池且电量低于 25%，或开了低电量模式（插电后自动恢复）；
                  · 合着盖子 3 小时没有请求（打开盖子后自动恢复）；
                  · config.local 里写了 LID_AWAKE=0；
                  · 守护没在运行：切回电脑模式、关闭酒馆、守护退出。
                  放开时 Mac 和手机都会收到通知。开着时别把 Mac 装进包里（发热）。
                  电量、时长可在 launcher/config.local 改：LID_BATTERY_FLOOR=25
                  LID_IDLE_HOURS=3；LID_AWAKE=0 临时停用。

TT 守护（更多 > TT 守护，需要 root + KernelSU）
                  手机上的数据保护模块（tt-root-module）：自动备份、实时副本、一键恢复、保活。
                  手机上的界面：KernelSU → 模块 → TT 守护；装和更新都在那里点，菜单只提示有新版本。
  看状态（更多 > TT 守护 > 1）
                  手机上的版本和最新版本、TT 开没开、上次备份、电脑上次拷走备份。
  立即拉一次备份（更多 > TT 守护 > 2）
                  把手机上的新备份拷到电脑（tavern/phone-backups/tt）。
  电脑自动拉备份（更多 > TT 守护 > 3）
                  开 / 关：开着时每分钟看一次，手机连着且有新备份就拷过来。
                  2、3 要把 tt-root-module clone 到本仓库同级目录（config.local 里 TT_MODULE_DIR 可改）。
  从备份恢复（更多 > TT 守护 > 4）
                  选一份 → 确认 → 恢复。TT 要先在手机的最近任务里划掉（这里不替你关）；
                  电量低于 15% 时不恢复。恢复前模块会先另存现在的数据。

生图（更多 > 生图 >）
  启动生图
                  启动本地 ComfyUI（端口 8188）。用 NovelAI 出图时不需要。
  关闭生图
                  生图很占内存，不用时关掉。

账号和维护（更多）
  登录 Claude（更多）
                  登录 Claude 订阅账号，一般只需要一次。
  修复依赖（更多）
                  提示「缺少依赖 / Cannot find module」时重装程序库，不动聊天记录。
  打开日志（更多）
                  proxy.log 每轮一行：耗时、缓存读写、输出；出错时附上最后几十行求助。
  开机自动启动（更多）
                  开 / 关。常用 TauriTavern 时方便；手机模式开着时守护也会一起启动。
                  开启的那一刻也会马上在后台启动一次（已经在运行的跳过）。
  本机TT导入（更多）
                  （测试用）电脑酒馆 → 这台 Mac 上的 TauriTavern，一键导入 / 更新：聊天、角色卡、
                  世界书、预设、图片、第三方扩展；可选把扩展设置（柏宝绘、MVU、小白X、
                  酒馆助手、提示词模板、正则、CCST）和对话补全设置（当前预设、
                  模型、各项开关）一起导入。单向：TT 独有的文件留着，
                  TT 上更新过的不覆盖；被覆盖的旧文件先备份。会先关掉 TT，导完再打开。

代理还在跑旧版本时（更新了代码没重启），第一行下面会提示，按对应字母就重启。

符号：✓ 正常   ! 提醒   ✗ 错误（下面有「解决办法」）

常见问题
  发消息报错 / 没反应：先「检查状态」；登录失效就「登录 Claude」。
  端口被占用：窗口里写了是哪个程序，关掉它或重启电脑。
  CCST 面板状态点红色：代理没运行，「启动酒馆」；或者代理拒绝了连接（手机上多半是
  访问密码不对：重新粘贴首页显示的「手机连接码」，或跑一次「同步手机」自动填好）。黄色：没登录。
  更新扩展后不生效：「重启代理」，再刷新浏览器页面；手机上的扩展用「同步手机」更新。
  「检查状态」提示代理还是旧版本：没在生成回复时「重启代理」。
  在手机上管 Mac：TT → 扩展 → CCST → 其他，「Mac 遥控」：看 Mac 电量、盖子、
  合盖不睡；重启代理、同步手机（在 TT 里按钮叫「仍要同步（未测试）」：TT 自带同步和备份，建议用它）、
  看日志（可复制）。本地生图和合盖不睡的开关只在这份菜单里，手机面板上没有。
  手机上提示「连不上代理」：Mac 睡眠了或换了 Wi-Fi；连回来后会提示「代理已恢复」。
  Mac 换了地址：在手机的卡片 / 面板「其他 → 手机连接」里重新粘贴首页显示的「手机连接码」，或在 Mac 上跑一次「同步手机」自动改好。
  合上盖子手机就断：没装「合盖不睡」，或电量低 / 3 小时没用被自动放开（会有通知）。
  「检查状态」提示 No route to host（守护连不上手机的无线调试）：macOS 的「本地网络」权限只给了
  终端，后台（守护、开机启动）拉起的 adb 连不了局域网。插一次 USB 线，或在「系统设置 → 隐私与
  安全性 → 本地网络」里允许「终端」。守护遇到这个错误 10 分钟才重试一次。
  在菜单窗口里按 Ctrl-C 不会关掉已经启动的代理、酒馆和守护（它们在后台单独运行）；要关用「关闭酒馆」。
