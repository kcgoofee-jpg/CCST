# 使用指南

[README](../README.md) 的详细版（旧版 README 在 [归档](归档/README-6.0.1.md)）。

## 三样东西

CCST 由三样东西组成：

| 东西 | 是什么 | 在哪 |
| --- | --- | --- |
| 面板 | 酒馆里的扩展：连接引导、额度和缓存状态、诊断 | 浏览器里的酒馆（TauriTavern 也能装） |
| 代理（插件或独立） | 把酒馆的请求转给 Claude，负责缓存排布、防丢回复、额度统计。两种跑法：作为**酒馆服务器插件**随酒馆启动；或**独立运行**（`npm start`） | 运行酒馆的那台电脑 |
| 一键安装器 | 把代理装成原版酒馆的服务器插件：Mac 在终端粘贴一行（`install-plugin-mac.sh`），Windows 双击 `.bat`（`installer/`） | 只用于原版酒馆 |

主要用法是**原版酒馆**：一键安装器把代理装进酒馆的 `plugins/`，代理随酒馆启动，面板通过扩展装上。

```
 浏览器（酒馆 + 面板）──▶ SillyTavern ──(服务器插件 = 代理)──▶ Claude
                        └────────── 同一台电脑，同一个进程 ──────────┘
```

## 原版酒馆

一键安装器的步骤见 [README 的「安装」](../README.md#安装)；装好以后就是下面这些。Mac 不要双击下载来的 `.command`（macOS 15 以上会被系统拦住，见下面「常见问题」），用终端那一行；Windows 的 `.bat` 不受影响。


### 使用

#### 首次引导

第一次打开面板、酒馆还没连上代理时，面板顶部出现一条引导，每步只看一件事，做完自动往下走：

1. **装代理**：Mac 在「终端」粘贴一行命令，Windows 下载安装程序双击运行；装好后重启酒馆。面板每几秒问一次代理，连上就进下一步。
2. **登录**：代理在线但没登录 Claude 时，给出要运行的那一条命令（`npm run login`），登录后自动进下一步。
3. **连接**：「一键连接」，然后「完成」。

已经连上的用户不会看到引导。「跳过引导」直接收起；想再看一遍：**设置 → 重新引导**（最下面）。

1. 打开「扩展」里的 **CCST** 面板。没连上时面板只显示一张卡片，告诉你缺什么（代理没启动 / 没登录 / 酒馆还没接上）和唯一一个按钮（启动代理的说明 / 登录说明 / **一键连接**）；连好后卡片消失，出现状态栏和两个页。
   **一键连接**会做这几件事：把酒馆的 API 来源设成本代理、提示词后处理设为「无」，然后**新建并选中一个叫「CCST」的连接配置，模型沿用你已选的 Claude 模型，没有就选 Opus 4.6**（已经有「CCST」配置就更新它），并弹出提示请你到酒馆「API 连接」里核对来源、地址和模型。你原来的连接配置不动，不会被覆盖。
2. 选模型和思考：都用酒馆自己的设置。模型在「API 连接」的模型下拉框里选（Opus 5.5 / Opus 4.6 / Sonnet 5.5 / Fable 5.1 等）；思考用预设里的「推理强度」：Auto 是模型默认，Minimum 是不思考（总会思考的模型上按最低深度），Low / Medium / High / Maximum 对应各档。两样都跟着预设保存。
3. 开始聊天。

「提示词后处理」要设为「无」，一键连接时会自动改好。思考过程显不显示跟随酒馆的「显示模型思维」。后台请求（总结、生图 tag、变量更新等被酒馆标成静默生成的）一律不思考。

面板顶部一行状态栏：在线点 · 模型 · 推理强度（不是 Auto 时）· 订阅 · 5 小时额度；点一下打开「状态」页。代理断了、没登录时，状态栏下多一张提示卡。

**生成进度**：面板最上面那一行状态栏会跟着回复变化。发出消息后显示「思考中 12 秒」，出字后显示「写作中 1,234 字」，写完显示「完成 · 1,850 字 · 38 秒 · 缓存 94%」，约 6 秒后变回平时的模型 / 额度。回复补回、断线 / 恢复、换了模型、被截断这些提示，都用酒馆自己的弹窗（右上角）显示。

| 面板页 | 内容 |
| --- | --- |
| 状态 | 最新回复的可靠检查（模型拒绝 / 被截断 / 空回复，只在出现时显示一行）、预设把思维链写进正文时的提示、上一轮缓存命中和原因（只看**当前聊天**；第一轮本来读不到缓存，用中性提示）、额度花在哪、上下文占用和输出速度、5 小时 / 7 天额度和消耗速度、用量（折叠）、诊断（「导出诊断文件」：一个文件里先是报告、后是原始数据，含角色卡和聊天原文，私发给作者） |
| 设置 | 连接（代理版本、代理地址、重新连接）、缓存（缓存有效期 1 小时 / 5 分钟；世界书移到本轮消息）、排查（查看发给模型的内容：代理内存里最近一次请求整理后的系统提示词和聊天记录）、重新引导 |

其余都固定好了，不用设置：会话续接、深度注入保持原位、发言后的注入并进发言、记录发给 Claude 的原始请求（供诊断文件用，只在代理内存里）。排查时可以用环境变量关掉（见最后的表）。

**回复不会再丢**：浏览器或 App 中途断开、页面被关掉时，收到的回复可能来不及存，或者断在一半。现在每次请求带一个「槽位」（聊天、楼层、第几个回复和你那句话的哈希，不含内容），代理写完后把回复按槽位存在内存里（不落盘，最多 40 个聊天，6 小时）。中途断开时代理照样写完；你按「停止」时面板会通知代理停下并丢掉这条，不会再补回。重新打开聊天、切回页面或连回代理时，只有这几种情况会补回：最后一楼是空的或「...」、写到一半断了（面板在写的过程中做了标记）、页面在存盘前就被关了（聊天停在你的发言上，补一楼上去）。你编辑过、删掉或按停止的回复一律不动。

### 省额度：让缓存生效

长对话里，每轮要把整段聊天记录发给 Claude。命中缓存的部分按很低的价格读；从第一个和上一轮不同的字起，后面整段都要重新写入。实测订阅里读缓存几乎不花额度，**额度主要花在输出（含思考）和重新写入上**。所以要紧的不是命中率数字，而是别让长聊天整段重写。

代理自动做这些：

- **关键词世界书移到本轮消息**（默认开，设置里可关）：见 [README](../README.md#世界书移到本轮消息默认开可以关)。
- 角色卡的深度 0 注入接到你的发言末尾；和之前某轮一字不差的长注入换成一句说明。
- 深度 3 以上的注入移到本轮发言前，旧消息保持原样。
- 预设放在聊天记录后面的条目改了（开关、编辑），之前各轮里的旧版本一起换成新的，只重写这一轮。
- 代理重启后，CLI 的环境信息固定放在历史开头（按模型存在 `data/cli-context.json`，没有聊天内容），重启后第二轮起就能命中。

自己能做的：别用按楼层改写旧消息的正则（如「5 楼外只发摘要」）；换预设、改角色卡会让那一轮整段重写，属于正常。缓存有效期默认 1 小时，两楼之间隔十几分钟也能命中；连续快聊可以在设置里改成 5 分钟（写入更便宜，停顿超过 5 分钟就整段重写）。

### 更新与卸载

- **更新代理**：装成酒馆插件的：再运行一次一键安装（Mac 粘贴同一行，Windows 再双击），或在 `plugins/CCST` 里 `git pull`（或重新 `node plugins.js install`），然后重启酒馆。单独运行的：在仓库里 `git pull && npm install`，再重启 `npm start`。
- **更新面板**：酒馆「扩展」管理里更新 CCST。
- **卸载**：装成酒馆插件的删掉 `plugins/CCST`。单独运行的停掉 `npm start`，删掉仓库文件夹。聊天记录在酒馆自己的数据里，不受影响。

### 只跑代理（命令行）

TauriTavern 跑不了服务器插件；或者不想把代理装进酒馆时，可以在同一台电脑上单独运行代理：

```bash
git clone https://github.com/kcgoofee-jpg/CCST
cd CCST
npm install
npm run login
npm start
```

代理要一直开着，地址 `http://127.0.0.1:8901/v1`。面板从「扩展 → 安装扩展」安装，地址填本仓库。

### 只给本机用

代理只接受同一台电脑的请求，其他设备（手机、另一台电脑）一律拒绝。手机上用的话，打开电脑上酒馆的网页即可：聊天请求由电脑上的酒馆转给代理。

## 常见问题

**双击脚本提示「无法验证开发者」**：浏览器下载来的 `.command` 文件在 macOS 15 以上会被拦（旧版 CCST 的 Mac 安装包就是这样）。现在原版酒馆的 Mac 安装改成终端一行（`install-plugin-mac.sh`），不会遇到。已经下载了旧的 `.command` 的话：系统设置 → 隐私与安全性 → 拉到底点「仍要打开」，或者直接换成终端那一行。

**Opus 5.5 第一轮就报「套取推理过程」（reasoning_extraction）**：预设或角色卡的世界书里有要求把思考写进正文的条目（常见写法：「用全英文输出 `<draft_notes>`」「先在 `<thinking>` 里思考」）。本扩展用原生思考，把那条关掉就行；面板发送前会指出是哪一句。想看写在正文里的思维链，就在「API 连接」换成 Opus 4.6，推理强度选 Minimum。

**面板显示「连接不到代理」**：原版酒馆确认 `enableServerPlugins: true` 并已重启；单独运行时确认 `npm start` 在运行。

**「未登录」或聊天中途认证失败**：在代理目录运行 `npm run login`（用运行酒馆的同一个系统用户），`npm run auth` 查看状态。

**「Failed to load @anthropic-ai/claude-agent-sdk」**：在代理目录重新 `npm install`（不加 `--omit=optional`），然后重启。

**1M 模型只有 200k 上下文**：部分套餐要开通额外用量才能用 1M。失败后代理会改用普通版一小时再重试。

**模型列表是空的**：再点一次一键连接，或在浏览器打开 `http://127.0.0.1:8901/status` 看代理状态。


## 高级：环境变量、接口、预设字段

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `CLAUDE_SUBSCRIPTION_PORT` | `8901` | 监听端口（改了要同步改面板「设置 → 连接」里的代理地址） |
| `CLAUDE_SUBSCRIPTION_HOST` | `127.0.0.1` | 监听地址。无论设成什么，其他设备的请求都会被拒绝 |
| `CLAUDE_SUBSCRIPTION_ALLOWED_HOSTS` | – | 额外允许的访问域名，逗号分隔（默认只接受本机地址，防 DNS 重绑定） |
| `CLAUDE_SUBSCRIPTION_ALLOWED_ORIGINS` | – | 额外信任的网页来源，逗号分隔 |
| `CLAUDE_SUBSCRIPTION_USE_RESUME` | `1` | `0` 表示把聊天记录压成一段文字发送 |
| `CLAUDE_SUBSCRIPTION_TURN_REPLAY` | `1` | `0` 表示关闭逐轮还原（聊天记录将无法命中缓存） |
| `CLAUDE_SUBSCRIPTION_INLINE_SYSTEM` | `1` | `0` 表示深度注入都提到系统提示词 |
| `CLAUDE_SUBSCRIPTION_LORE_TAIL` | `1` | `0` 表示关键词世界书留在系统提示词（面板没发设置时用这个值） |
| `CLAUDE_SUBSCRIPTION_FOLD_TAIL` | `1` | `0` 表示发言后的深度 0 注入不并进发言 |
| `CLAUDE_SUBSCRIPTION_DIAG_CAPTURE` | `1` | `0` 表示不记录发给 Claude 的原始请求（环境变量里是 socks 等非 http 代理时自动不记录） |
| `CLAUDE_SUBSCRIPTION_VERBATIM` | `1` | `0` 表示允许 CLI 展开聊天文字里的 `@路径` 和斜杠命令 |
| `CLAUDE_SUBSCRIPTION_REFUSAL_FALLBACK` | – | `on` 表示被安全机制拦下时允许 CLI 换模型重写 |
| `CLAUDE_SUBSCRIPTION_MAX_TURNS` | `1` | SDK 的轮数上限 |
| `CLAUDE_SUBSCRIPTION_SCRATCH_CWD` | `$TMPDIR/claude-max-rp` | CLI 子进程的工作目录（应在任何 git 仓库之外） |
| `CLAUDE_SUBSCRIPTION_AUX_THINKING` | `off` | 没带面板设置的辅助请求是否思考 |
| `CLAUDE_SUBSCRIPTION_CLAUDE_PATH` | – | 指定 `claude` 可执行文件路径 |
| `CLAUDE_SUBSCRIPTION_NO_UI_INSTALL` | – | `1` 表示不自动安装面板 |

以 `CLAUDE_SUBSCRIPTION` 开头的变量都不传给 CLI；shell 里的 `ANTHROPIC_API_KEY`、`CLAUDE_CODE_USE_BEDROCK` 这类会被清掉，不会悄悄改变计费。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/status` | SDK 和登录状态 |
| GET | `/v1/models` | 模型列表 |
| GET | `/v1/usage/quota` | 订阅额度 |
| GET | `/v1/usage/stats` | 用量统计和上一轮缓存分析 |
| GET | `/v1/debug/last` | 最近一次聊天请求（代理整理后，只在内存里） |
| GET | `/v1/diag/report`、`/v1/diag/full` | 诊断报告 / 原始数据（含聊天内容） |
| POST | `/v1/chat/completions` | 聊天（SSE 和 JSON） |
| POST | `/v1/replies/:slot/cancel` | 停止并丢掉暂存的回复（面板的停止键） |

请求体可带 `claude_subscription: { effort, thinking, show_reasoning, lore_tail, cache_ttl }` 控制这些设置，或用标准的 `reasoning_effort` 字段。预设文件可带 `extensions.claude_max`：`loreTail`、`cacheTtl`，切到该预设时面板自动应用、切走时恢复；`byModel` 按模型开关预设条目，例如 `{ "claude-opus-4-6": { "prompts": { "<条目 id>": true } }, "claude-opus-5-5": { "prompts": { "<条目 id>": false } } }`（Opus 4.6 开思维链条目，Opus 5.5 关掉）。旧版的 `effort`、`thinking` 等字段不再生效，思考用预设自己的推理强度。
