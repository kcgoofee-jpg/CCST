# 使用指南

[README](../README.md) 的详细版（旧版 README 在 [归档](归档/README-6.0.1.md)）。

## 三样东西

CCST 由三样东西组成：

| 东西 | 是什么 | 在哪 |
| --- | --- | --- |
| 面板 | 酒馆里的扩展：切模型、思考深度、状态、连接引导 | 浏览器里的酒馆（TauriTavern 也能装） |
| 代理（插件或独立） | 把酒馆的请求转给 Claude，负责缓存排布、防丢回复、额度统计。两种跑法：作为**酒馆服务器插件**随酒馆启动；或**独立运行**（`npm start`） | 运行酒馆的那台电脑 |
| 一键安装器 | 把代理装成原版酒馆的服务器插件：Mac 在终端粘贴一行（`install-plugin-mac.sh`），Windows 双击 `.bat`（`installer/`） | 只用于原版酒馆 |

主要用法是**原版酒馆**：一键安装器把代理装进酒馆的 `plugins/`，代理随酒馆启动，面板通过扩展装上。

```
 浏览器（酒馆 + 面板）──▶ SillyTavern ──(服务器插件 = 代理)──▶ Claude
                        └────────── 同一台电脑，同一个进程 ──────────┘
```

## 原版酒馆

一键安装器的步骤见 [README 的「安装」](../README.md#安装)；装好以后就是下面这些。Mac 不要双击下载来的 `.command`（macOS 15 以上会被系统拦住，见下面「常见问题」），用终端那一行；Windows 的 `.bat` 不受影响。


### 使用

#### 首次引导

第一次打开面板、酒馆还没连上代理时，面板顶部出现一条引导，每步只看一件事，做完自动往下走：

1. **装代理**：Mac 在「终端」粘贴一行命令，Windows 下载安装程序双击运行；装好后重启酒馆。面板每几秒问一次代理，连上就进下一步。
2. **登录**：代理在线但没登录 Claude 时，给出要运行的那一条命令（`npm run login`），登录后自动进下一步。
3. **连接**：「一键连接」，然后「完成」。

已经连上的用户不会看到引导。「跳过引导」直接收起；想再看一遍：**设置 → 重新引导**（最下面）。

1. 打开「扩展」里的 **CCST** 面板。没连上时面板只显示一张卡片，告诉你缺什么（代理没启动 / 没登录 / 酒馆还没接上）和唯一一个按钮（启动代理的说明 / 登录说明 / **一键连接**）；连好后卡片消失，出现状态栏和三个页。
   **一键连接**会做这几件事：把酒馆的 API 来源设成本代理、提示词后处理设为「无」，然后**新建并选中一个叫「CCST」的连接配置，模型沿用你已选的 Claude 模型，没有就选 Opus 4.6**（已经有「CCST」配置就更新它），并弹出提示请你到酒馆「API 连接」里核对来源、地址和模型。你原来的连接配置不动，不会被覆盖。
2. 选模型：面板「聊天」页一键切 Opus 5.5 / Opus 4.6，或在「API 连接」的模型下拉框里选（Sonnet 5、Fable 5.1 等）。预设可以推荐模型（`extensions.claude_max.model`），切到这个预设时面板自动换过去；只换模型，不动代理地址（酒馆自己的「预设绑定连接」会连地址一起换）。
3. 开始聊天。

酒馆自带的「推理强度」保持「自动」，思考深度在面板里设置。「提示词后处理」要设为「无」，一键连接时会自动改好。

面板顶部一行状态栏：在线点 · 模型 · 走哪 · 按什么计费（「本机代理 · 订阅」）· 5 小时额度（只在走订阅时）；点一下打开「状态」页。「仅下一轮」加深生效时多显示「下一轮 高」。代理断了、没登录、访问密码不对时，状态栏下多一张提示卡。

**生成进度**：面板最上面那一行状态栏会跟着回复变化。发出消息后显示「思考中 12 秒」，出字后显示「写作中 1,234 字」，写完显示「完成 · 1,850 字 · 38 秒 · 缓存 94%」，约 6 秒后变回平时的模型 / 额度。回复补回、断线 / 恢复、换了模型、被截断这些提示，都用酒馆自己的弹窗（右上角）显示。

**要调的只有两样**：「聊天」页的模型（Opus 5.5 / 4.6 / Sonnet 5.5）和思考（不思考 / 自动 / 低 / 中 / 高 / 超高 / 最大，加「仅下一轮加深」）。思考深度按模型处理：4.5 代的模型（Haiku / Sonnet / Opus 4.5）不发思考深度；Opus / Sonnet 4.6 没有「超高」，按「高」；总会思考的模型（Opus 5.5、Sonnet 5.5、Fable……）上「不思考」是灰的，并显示实际深度。其余都自动处理：

| 以前的开关 | 现在 |
| --- | --- |
| 会话续接、深度注入保持原位、世界书移到末尾、注入并进发言 | 默认值 + 预设自带的推荐（切预设自动套用、切走恢复）；世界书和发言后注入由代理按每个聊天的实际变化决定挪不挪 |
| 思考模式 | 并进「聊天」页的思考（「不思考」）；「始终思考」在「设置 → 高级」里 |
| 显示思考过程 | 跟随酒馆的「显示模型思维」 |
| 后台请求的思考深度 | 默认「低」；在「设置 → 高级」里可改成跟随「聊天」页。只管借用酒馆当前连接、被标成静默生成的后台请求，只对总会思考的模型（Opus 5.5、Sonnet 5.5、Fable……）有影响，扩展自己配了独立 API 的管不到 |
| 身份模式、代理地址 | 设置页；保存完整请求在「设置 → 高级」 |

原来的开关都还在：「显示思考过程」「身份模式」在设置页，「始终思考」和缓存与上下文的开关在「设置 → 高级」（默认折叠），排查问题时用。

| 面板页 | 内容 |
| --- | --- |
| 聊天 | 模型（只写名字和一个短标签）、思考（一排按钮）、「仅下一轮加深」 |
| 状态 | 最新回复的可靠检查（模型拒绝 / 被截断 / 空回复，只在出现时显示一行）、上一轮缓存命中和原因（只显示**当前聊天**的；这个聊天还没有回复时写「这个聊天还没有回复」，不会拿别的聊天的数据顶替；第一轮本来读不到缓存，用中性提示，不当成出错；回复写完后自动刷新）、5 小时 / 7 天额度（点「刷新」查看，之后每条回复写完自动查一次，不会一直转圈）、用量（可折叠，默认折叠，标题上写近 7 天请求数；回复写完后自动刷新）、世界书缓存（只在有关键词条目时出现：一键设为常驻）、诊断（复制诊断报告、下载完整请求；「记录原始请求」默认开，环境变量里是 socks 等非 http 代理时代理自动不记录） |
| 设置 | 连接（代理版本、本机代理地址、重新连接）、显示思考过程、身份模式、高级（折叠：后台请求思考深度、始终思考、缓存与上下文的开关、保存最近一次完整请求 + 查看）、重新引导 |

**回复不会再丢**：浏览器或 App 中途断开、页面被关掉时，收到的回复可能来不及存，或者断在一半。现在每次请求带一个「槽位」（聊天、楼层、第几个回复和你那句话的哈希，不含内容），代理写完后把回复按槽位存在内存里（不落盘，最多 40 个聊天，6 小时）。中途断开时代理照样写完；你按「停止」时面板会通知代理停下并丢掉这条，不会再补回。重新打开聊天、切回页面或连回代理时，只有这几种情况会补回：最后一楼是空的或「...」、写到一半断了（面板在写的过程中做了标记）、页面在存盘前就被关了（聊天停在你的发言上，补一楼上去）。你编辑过、删掉或按停止的回复一律不动。

### 省额度：让缓存生效

长对话里，大部分额度花在每轮重新读取整段聊天记录上；命中缓存时这部分只按约十分之一计费（Anthropic 的计费规则）。能不能整段命中取决于预设、世界书和其他扩展，下面是预计需要同时满足的条件：

1. 不用按楼层改写旧消息的正则（如「5 楼外只发摘要」）；
2. 世界书改为常驻，不按关键词触发（面板「状态」页可一键转换，会先备份）；
3. 深度注入提到系统提示词里（预设可写 `extensions.claude_max.inlineSystem: false` 自动设置）。

在一次实测的聊天里，三条都满足后缓存命中率从 46% 提高到 95%、每轮约省 43% 额度；别的预设、世界书和扩展组合没有逐一实测，效果只能当预计。没命中时，面板会写明原因。

做不到的时候代理会自己补救：按关键词触发、每轮变化的世界书块移到本轮消息开头（系统提示词里留一行固定说明；新聊天从第一轮起就这样做，不再先整段重写两轮来「学」），角色卡的深度 0 注入接到你的发言末尾，深度 3 以上的注入（「保持原位」模式下原本会并进旧消息、每轮挪位置）移到本轮发言前，分界点按实际发出的提示词计算，学到的规律跨代理重启保留。用真实聊天的连续楼层空跑检查（不调用模型）：两种深度注入模式下在这批聊天上读到约 96% 的缓存（别的聊天不一定）。代理重启后，CLI 会把它的环境信息补在第一轮的末尾、之后又变成中间消息，以前重启后的第二轮必定整段重写；现在把这段信息固定放在历史开头（按模型存一份在 `data/cli-context.json`，只有账号和环境信息，没有聊天内容），重启后第二轮起就能命中。缓存有效期是 1 小时（订阅走 Claude Code 的默认），两楼之间隔十几分钟也能命中。

### 更新与卸载

- **更新代理**：装成酒馆插件的：再运行一次一键安装（Mac 粘贴同一行，Windows 再双击），或在 `plugins/CCST` 里 `git pull`（或重新 `node plugins.js install`），然后重启酒馆。单独运行的：在仓库里 `git pull && npm install`，再重启 `npm start`。
- **更新面板**：酒馆「扩展」管理里更新 CCST。
- **卸载**：装成酒馆插件的删掉 `plugins/CCST`。单独运行的停掉 `npm start`，删掉仓库文件夹。聊天记录在酒馆自己的数据里，不受影响。

### 只跑代理（命令行）

TauriTavern 跑不了服务器插件；或者不想把代理装进酒馆时，可以在同一台电脑上单独运行代理：

```bash
git clone https://github.com/kcgoofee-jpg/CCST
cd CCST
npm install
npm run login
npm start
```

代理要一直开着，地址 `http://127.0.0.1:8901/v1`。面板从「扩展 → 安装扩展」安装，地址填本仓库。

### 实验性：Windows 酒馆工具菜单

以下脚本只做过语法检查，没有在真机上运行过，可能需要自己排错。欢迎反馈。

Windows 上可以不装成酒馆插件，用菜单单独管理代理：

  1. 装 [Node.js](https://nodejs.org) LTS（安装时保持默认选项）。
  2. 下载本仓库（Code → Download ZIP）解压；用原版酒馆的话放在 `SillyTavern` 文件夹旁边。
  3. 双击 `launcher\windows\酒馆工具.bat` 打开菜单（说明见 `launcher/使用说明.txt`）：首页按 `3` 进「更多」，选「登录 Claude」浏览器登录订阅（只需一次），回首页按回车启动：它会先自检，缺依赖时问你要不要装。
  4. 酒馆里打开 CCST 面板，点「一键连接」。
  关闭、检查、开机自动启动也都在这个菜单里。自定义路径写在 `launcher\config.local.ps1`，例如 `$ST_DIR = 'D:\SillyTavern'`。

### 访问密码

代理默认只监听 `127.0.0.1`，只给本机用。其他设备的请求必须带访问密码（`Authorization: Bearer <密码>` 或 `X-Claude-Max-Key`），本机不需要；没设密码时，就算代理绑到 `0.0.0.0` 也会拒绝所有其他设备的请求。对应的环境变量是 `CLAUDE_SUBSCRIPTION_HOST=0.0.0.0`、`CLAUDE_SUBSCRIPTION_LAN_KEY=<密码>`。拿到密码的人用的是你的订阅，不要外传。


## 常见问题

**双击脚本提示「无法验证开发者」**：浏览器下载来的 `.command` 文件在 macOS 15 以上会被拦（旧版 CCST 的 Mac 安装包就是这样）。现在原版酒馆的 Mac 安装改成终端一行（`install-plugin-mac.sh`），不会遇到。已经下载了旧的 `.command` 的话：系统设置 → 隐私与安全性 → 拉到底点「仍要打开」，或者直接换成终端那一行。

**Opus 5.5 第一轮就报「套取推理过程」（reasoning_extraction）**：预设或角色卡的世界书里有要求把思考写进正文的条目（常见写法：「用全英文输出 `<draft_notes>`」「先在 `<thinking>` 里思考」）。本扩展用原生思考，把那条关掉就行；面板发送前会指出是哪一句。想看写在正文里的思维链，就在「聊天」页切到 Opus 4.6 并把思考关掉。

**面板显示「连接不到代理」**：原版酒馆确认 `enableServerPlugins: true` 并已重启；单独运行时确认 `npm start` 在运行。

**「未登录」或聊天中途认证失败**：在代理目录运行 `npm run login`（用运行酒馆的同一个系统用户），`npm run auth` 查看状态。

**「Failed to load @anthropic-ai/claude-agent-sdk」**：在代理目录重新 `npm install`（不加 `--omit=optional`），然后重启。

**1M 模型只有 200k 上下文**：部分套餐要开通额外用量才能用 1M。失败后代理会改用普通版一小时再重试。

**模型列表是空的**：再点一次一键连接，或在浏览器打开 `http://127.0.0.1:8901/status` 看代理状态。


## 高级：环境变量、接口、预设字段

| 环境变量 | 默认值 | 作用 |
| --- | --- | --- |
| `CLAUDE_SUBSCRIPTION_PORT` | `8901` | 监听端口（改了要同步改面板「设置 → 连接」里的代理地址） |
| `CLAUDE_SUBSCRIPTION_HOST` | `127.0.0.1` | 监听地址。改成 `0.0.0.0` 要同时设访问密码（见上面「访问密码」） |
| `CLAUDE_SUBSCRIPTION_LAN_KEY` | – | 访问密码：其他设备的请求要带它 |
| `CLAUDE_SUBSCRIPTION_ALLOWED_HOSTS` | – | 额外允许的访问域名，逗号分隔（默认只接受本机地址，防 DNS 重绑定） |
| `CLAUDE_SUBSCRIPTION_USE_RESUME` | `1` | `0` 表示把聊天记录压成一段文字发送 |
| `CLAUDE_SUBSCRIPTION_TURN_REPLAY` | `1` | `0` 表示关闭逐轮还原（聊天记录将无法命中缓存） |
| `CLAUDE_SUBSCRIPTION_VERBATIM` | `1` | `0` 表示允许 CLI 展开聊天文字里的 `@路径` 和斜杠命令 |
| `CLAUDE_SUBSCRIPTION_SCRATCH_CWD` | `$TMPDIR/claude-max-rp` | CLI 子进程的工作目录（应在任何 git 仓库之外） |
| `CLAUDE_SUBSCRIPTION_AUX_THINKING` | `off` | 没带面板设置的辅助请求是否思考 |
| `CLAUDE_SUBSCRIPTION_CLAUDE_PATH` | – | 指定 `claude` 可执行文件路径 |
| `CLAUDE_SUBSCRIPTION_NO_UI_INSTALL` | – | `1` 表示不自动安装面板 |
| `CLAUDE_SUBSCRIPTION_BACKEND` | – | 代理后端：`subscription` / `apikey`，优先于面板里选的 |
| `CLAUDE_SUBSCRIPTION_API_KEY` | – | API 密钥后端的密钥，优先于 `data/backend.json`（以 `CLAUDE_SUBSCRIPTION` 开头的变量都不传给 CLI）。后端名、密钥、访问密码的值会去掉最外层引号。shell 里的 `ANTHROPIC_API_KEY`、`CLAUDE_CODE_USE_BEDROCK` 这类会被清掉，不会悄悄改变计费 |
| `CLAUDE_SUBSCRIPTION_BACKEND_FILE` | `data/backend.json` | 后端配置文件位置 |

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/status` | SDK 和登录状态；`rateLimit` 字段是最近一次回复里 CLI 报的额度窗口状态，只记录，不影响行为 |
| GET | `/v1/models` | 模型列表 |
| GET | `/v1/usage/quota` | 订阅额度（非订阅后端返回 `notSubscription: true`） |
| GET / POST | `/v1/backend` | 看 / 改代理后端（不返回密钥；其他设备访问要访问密码） |
| GET | `/v1/usage/stats` | 用量统计和上一轮缓存分析 |
| GET | `/v1/debug/last` | 最近一次完整请求（需打开调试开关） |
| GET | `/v1/diag/report`、`/v1/diag/full` | 诊断报告（不含聊天内容）/ 完整请求 |
| POST | `/v1/chat/completions` | 聊天（SSE 和 JSON） |

请求体可带 `claude_subscription: { effort, thinking, show_reasoning, use_resume, system_placement, debug_dump }` 控制这些设置。预设文件可带 `extensions.claude_max`（`effort`、`thinking`、`showReasoning`、`useResume`、`inlineSystem`、`loreTail`、`foldTail`、`identityMode`），切到该预设时面板自动应用，切走时恢复。
