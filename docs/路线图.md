# 路线图

> 2026-10-02 · 基于 5.1.0。计划会随反馈调整，版本号是目标不是承诺。

## 目标

**酒馆里用 Claude 的懒人层：不管 Claude 从哪来，装上就是最好的状态。**

订阅、官方 API 密钥、OpenRouter、AWS Bedrock、Google Vertex、各种 OpenAI 兼容中转，今天在酒馆里各有各的坑：缓存要自己调、新模型要手动加、预设和模型对不上、手机切后台回复就丢、电脑和手机两头不一致。CCST 要做的是：选好来源、点一次连接，剩下的自动处理。

## 现在（5.1）

| | 订阅（本机代理） | 官方 API / OpenRouter（直连） | 其他来源 |
| --- | --- | --- | --- |
| 面板：模型切换、预设推荐、发送前检查、拒绝 / 截断提示（实验性体检默认关） | ✓ | ✓ | 部分（按 OpenAI 兼容处理） |
| 缓存排布（世界书挪位、会话续接） | ✓ | 用酒馆自带设置 | – |
| 防丢回复、额度 / 用量、手机遥控 | ✓ | – | – |
| Mac ↔ 手机同步（含 API 设置和密钥） | ✓ | ✓ | ✓ |

## 3.2 · 所有来源一个面板（已完成）

酒馆本身没有 Bedrock 来源，「Vertex AI」来源只接 Gemini，所以这两家只能经中转接入；酒馆的缓存设置在服务器 `config.yaml` 里，面板只能给出改法，不能代改；直连时酒馆不把用量传给网页，上一轮命中看不到。


- ✓ 面板识别能通到 Claude 的全部来源（Claude 官方源 / 反向代理、OpenRouter、Electron Hub、NanoGPT、AI/ML API、CometAPI、自定义地址），状态栏写明「走哪 · 按什么计费」。
- ✓ 「状态」页的缓存卡片：按来源给出 `config.yaml` 的推荐写法，一键复制；走本代理时照旧显示上一轮命中。
- ✓ 模型切换和「按模型自动切换思维链」覆盖上面所有来源（按各来源的模型命名对应）。
- ✓ Claude 官方源下拉框里缺的新模型自动补上（从本代理的模型列表，或面板自带的已知列表）。

## 3.3 · 代理多后端（已完成）

后端都经官方 Claude Code（Agent SDK）跑，只做它本身支持的：Bedrock、Vertex 靠 CLI 自带的开关，OpenRouter 和其他网关走 Anthropic 兼容接口（Bearer 令牌）。用量接口不给金额，花费是 token 数 × 官方价的估算；Bedrock / Vertex / OpenRouter 的实际价格以各自账单为准。Mythos 只有官方 API 有。

- ✓ 代理后端可选：订阅（默认）、Anthropic API 密钥、Bedrock、Vertex、OpenRouter、Anthropic 兼容网关。缓存排布、防丢回复、用量统计对所有后端生效；模型名按后端自动换。
- ✓ 面板「设置 → 代理后端」切换并填写，存在代理那台电脑（`data/backend.json`，0600），密钥不回传；也可用环境变量。每个密钥只发给它自己的服务，shell 里残留的密钥 / 开关会被清掉。
- ✓ 用量按后端分开统计，API 类后端显示估算花费；不是订阅时隐藏订阅额度。

## 4.0 · 原版酒馆优先（已完成）

- ✓ 主线只适配原版 SillyTavern（服务端插件 + 面板，Chrome / Edge）；手机、TauriTavern、Mac 专用功能收进「其他」，保留但不再开发（TauriTavern 已自带同步）。
- ✓ 代理和面板重构分层；面板重新设计（首次连接卡片、一行状态栏、模型卡片）；启动器首页只管原版酒馆。

## 4.1 · 一键部署（已完成）

- 扩展：酒馆「安装扩展」填仓库地址即可，首次打开有引导（选来源 → 连接 → 完成）。
- 代理：Mac 已正式；Windows、Linux 真机实测后转正。
- 云酒馆：服务器上一条命令装代理，自动生成访问密码；提供 Dockerfile 和 compose 示例（镜像从 v5.1.0 起发布到 GHCR，待在 GitHub Packages 里设为公开）。

## 4.2 · 一键安装包（已完成）

- ✓ 面板连不上代理时，卡片里直接下载「一键安装」：Mac 是压缩包里的 `.command`，Windows 是 `.bat` + `.ps1`；自己找酒馆、装依赖、引导登录 Claude。
- ✓ 一键连接前先确认，不覆盖你当前的连接，也不写占位密钥。

## 4.3 · 真机反馈修复（已完成）

- 一键连接新建并选中「CCST」连接配置（Opus 4.6），提示你核对；不动你原来的配置。
- 状态页只显示当前聊天的上一轮，没回复时说「这个聊天还没有回复」；额度手动刷新或每条回复后更新；用量可折叠。
- 体检只数真实回复，开场白不算；隐藏设定关键词保存后有反馈并立即复查。
- 「其他」整理：去掉面板上的「本地生图」「合盖不睡」按钮（启动器菜单里还在），同步手机在 TauriTavern 里提示未测试，看日志可复制，重新引导是直接的按钮。

- ✓ 灵动岛移除，生成进度进状态栏；面板提示和代理报错按「情况、影响、怎么办」重写；README 加英文版并带中英文切换；文档按三种用法重排（用法一原版酒馆 / 用法二 TauriTavern 与手机 / 用法三服务器）。

## 4.4 · 服务器部署（已完成，[#18](https://github.com/kcgoofee-jpg/CCST/issues/18)）

## 5.0 · 本机代理与手机连接（已完成，[里程碑](https://github.com/kcgoofee-jpg/CCST/milestone/7)）

原计划里的 4.6（预设体检、连接提示）和这一批改动合成一个版本。按[版本规范](版本规范.md)升主版本：Mac 的安装方式变了（终端一行安装，取代双击下载的 `.command`），启动器菜单结构变了，手机 / TauriTavern 连电脑上的代理明确只支持 Mac。

逐条见[更新记录](../CHANGELOG.md)的 5.0.0：

- ✓ **Mac 安装**：终端粘贴一行命令（`install-mac.sh`），避开 macOS 15 以上对下载的 `.command` 的拦截；Node 缺失才问一次，登录、桌面快捷方式、启动代理都直接做；做完直接进菜单，窗口不自己关。
- ✓ **启动器重新设计**：首页「下一步」一句话、最多 22 行；「手机」单独一页（连接码、二维码、开关，开 / 关各有确认）；维护和其他合并成「更多」；状态探测加缓存；文案统一成「代理」。
- ✓ **手机连接**：手机上整串粘贴「手机连接码」；扫码打开是大字说明页加复制按钮；面板、README、使用指南写明目前只支持 Mac。
- ✓ **面板**：重新连接保留已选模型；总会思考的模型上「不思考」灰掉并显示实际深度；回复结束自动刷新「上一轮」和用量；连接提示精简且同一预设只弹一次；第一轮缓存用中性提示；后台请求思考深度收进「高级」。
- ✓ **代理**：1M 上下文没有额度时自动降到普通版（识别新版命令行工具的报错措辞）；effort 按模型处理（4.5 代不发，4.6 的 xhigh 按 high）；记录 SDK 的额度窗口事件；环境变量的值去掉最外层引号。
- ✓ **镜像发布流程**：打 `v*` 标签时发布 GHCR 镜像（amd64 + arm64，先在 QEMU 下冒烟测试 arm64）。

## 之后

- **预设体检的其余几项**：思维链条目、段落计划、正则脚本是否和当前模型匹配（预设和模型是否匹配已在 5.1 完成）。

- **接酒馆的函数调用**：把请求里的 `tools` 翻译给 Claude，调用时按 OpenAI 的 `tool_calls` 结束这一轮，结果回来后照常重放历史。让走酒馆函数调用的扩展（联网搜索、记忆、生图触发等）能用上订阅。默认关，先验证一条链路；要注意工具说明进前缀会影响缓存排布。

- **6 位配对码**（[#20](https://github.com/kcgoofee-jpg/CCST/issues/20)）：手机上输 6 位数字就连上，不用粘贴长串或扫码。Mac 显示一次性配对码（5 分钟、用一次、错 3 次作废），手机端在局域网里找到 Mac 后换取真正的访问密码；先验证手机 TauriTavern 的网页环境里并行探测局域网是否稳定，路由器开了「设备隔离」时仍连不上。
- **更准的限流提示**（[#21](https://github.com/kcgoofee-jpg/CCST/issues/21)）：用额度窗口事件区分「瞬时限流」和「窗口用完」，后者不再原地重试，429 提示写出具体的重置时间（要先在真实订阅上拿到预警 / 打满的样本）。
- 长聊天管理：分卷、摘要和缓存配合，不让总结插件把缓存打碎（[#1](https://github.com/kcgoofee-jpg/CCST/issues/1)）。
- 生图联动：生图请求的状态进状态栏，失败原因直接显示（[#3](https://github.com/kcgoofee-jpg/CCST/issues/3)）。

## 不做

- 订阅共享、拼车、多账号轮换、对外服务。
- 规避安全机制：拒绝后自动换模型重试、改写内容绕过审核。
- 涉及未成年人的内容：不导入、不调优，角色卡检查会提示。
