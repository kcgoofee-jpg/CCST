# 架构

## 运行时

```
酒馆 / TauriTavern ──(发消息)──▶ 面板 src/panel ──┬─▶ 直连：酒馆自己的 Claude 源 / OpenRouter
   （浏览器 / App）                 （改请求参数、     │
                                    检查、生成进度）    └─▶ 代理 src/proxy（本机 :8901，OpenAI 兼容）
                                                            │  会话续接、缓存排布、防丢回复、额度 / 用量
                                                            ▼
                                                   官方 Claude Code / Agent SDK（后端见 backend-config.js）
                                                            ▼
                                  Anthropic（订阅 / API 密钥）· Bedrock · Vertex · OpenRouter / 兼容网关

三种用法（组件的摆法）：
  一 原版酒馆   浏览器(酒馆+面板) ─▶ SillyTavern ─(服务器插件 = 代理，installer/ 一键安装)─▶ Claude
  二 TauriTavern 手机/Mac TT(面板，链接安装) ─(同一 Wi-Fi，访问密码)─▶ 电脑上独立代理(launcher/ 酒馆工具或 npm start，手机模式) ─▶ Claude
     launcher/ ──(adb)──▶ 手机：CCST 自带同步、手机模式通知、TT 守护（保留不开发；聊天同步用 TT 自带的）
  三 服务器     浏览器/TT ─(访问密码)─▶ 服务器上的代理(deploy/install.sh · Docker；或当酒馆插件) ─▶ Claude   （真机测试 4.4）
```

## 目录

| 路径 | 是什么 | 在哪运行 |
| --- | --- | --- |
| `manifest.json` | 酒馆扩展清单（酒馆要求放根目录），指向 `src/panel/` | — |
| `package.json` | 版本号唯一来源；`main` 指向 `src/proxy/plugin.js`（酒馆服务器插件入口）| — |
| `server.js` | 独立运行代理的入口（`npm start`、启动脚本）。只有一行，转到 `src/proxy/server.js`，留在根目录让老的启动方式不失效 | Node |
| `src/panel/` | 面板：`index.js`（启动入口）、`core/`、`shell.js`、`tabs/`、`features/`、`style.css`，见下面「面板」| 浏览器 / App WebView |
| `src/proxy/` | 代理，分层见下面「代理分层」；`plugin.js`（酒馆插件入口）、`server.js`（独立入口）；`paths.js` 统一给出仓库根目录和 `data/` | Node |
| `src/shared/` | 面板和代理 / 开发脚本共用的纯函数：体检、角色卡检查、世界书常驻、预设推荐、云端酒馆检测 | 两边 |
| `install-mac.sh` | Mac 终端一行安装 / 更新（用法二）：下载仓库 zip 到 `~/CCST`（覆盖代码，保留登录和数据），然后运行 `launcher/mac/首次安装.command`。终端自己下载的文件不带「来自网络」标记，不会被 macOS 拦 | 用户电脑 |
| `bin/claude-cli.js` | 调用随附的 Claude Code（登录、查登录状态：`npm run login`）| Node |
| `launcher/` | 一键脚本：`menu.mjs` 是三个系统共用的菜单，`core.mjs` 是共用的状态和动作，`phone.mjs` 是同步手机和 TT 守护（都无 npm 依赖，见下面「启动器」）；`mac/`（`酒馆工具.command` 启动壳、`首次安装.command`、`actions/*.zsh` 各项动作、`lib.zsh`、`menu-status.zsh`、`phone-connect.zsh`）、`windows/`（`酒馆工具.bat` + `claude-max.ps1`）、`termux/`；`phone_sync.py` 同步；`使用说明.txt` | 用户电脑 |
| `installer/` | 一键安装器（用法一）：`CCST安装.command`（Mac，打包成 `CCST-mac.zip`）、`CCST安装.bat` + `ccst-install.ps1`（Windows）；把代理装成酒馆服务器插件。Mac 的 zip 里的 `.command` 在 macOS 15 以上会被系统拦（[issue #22](https://github.com/kcgoofee-jpg/CCST/issues/22)）。环境变量 `CCST_BRANCH` 可指定分支 | 用户电脑 |
| `test/` | 单元测试：`*.test.js`（`npm test`）；`test/launcher/`（Python，`npm run test:py`）| 开发 / CI |
| `scripts/` | 开发脚本：门控 `gate.sh`、版本 `version.mjs` | 开发 |
| `docs/` | 设计文档（定位、架构、版本规范）和 `assets/` | — |
| `data/` | 运行时数据：用量、缓存记忆、调试记录。本机专用，不进仓库 | — |

## 代理分层

`src/proxy/` 从上到下四层，依赖只往下：

- `api/`：对外的接口。`routes.js` 是**唯一的路由表**（每条：方法、独立监听路径、酒馆插件路径、处理函数、CORS / Origin 规则），`registerRoutes(router, 'standalone' | 'plugin')` 把它挂到两个入口上——独立监听（`listener.js`，`/v1/*`）和酒馆插件（`plugin.js`，`/api/plugins/claude-subscription/*`，只挂面板同源要读的几条）。加接口只改路由表。`guards.js` 是 Host / Origin / 局域网密码 / CORS；`status.js` 是 `/status`。
- `core/`：对话主线：`chat.js`（请求 → SDK）、`sse.js`、`stops.js`、`system-prompt.js`、`sdk-loader.js`、`env.js`（子进程环境）、`models.js`、`transcript.js`。
- `features/`：会话与缓存布局（`session-store`、`jsonl-entries`、`turn-capture`、`system-placement`、`lore-tail`、`tail-block`、`cache-diag`）和其余功能（`reply-keeper`、`usage-stats`、`backend-config`、`oauth`（额度）、`debug-dump`、`errors-zh`、`settings`）。
- `platform/`：跟 Mac 启动器打交道。`launcher.js` 是**唯一**执行 `launcher/mac/lib.zsh` 的地方（`zsh()`、`logEvent()`、`tail()`、`launcherAvailable()`）；`control.js` 是手机遥控的动作表和处理函数，只通过 `launcher.js` 调 zsh。

## 启动器

- `launcher/core.mjs`（Node，三个系统同一份）：读 `config.local` / `config.local.ps1`、问代理（`/status`、`/v1/control/status`、`/v1/backend`）、版本对比、登录、装了什么（酒馆、TT、ComfyUI、TT 守护仓库）、端口探测、上次同步时间（菜单侧状态探测有 5 秒缓存）；Mac 上手机连着时用一次 `adb shell` 看手机（TT 开没开、在不在生成回复、TT 守护的版本 / 上次备份 / 在不在恢复，root 部分整条交给 `su -c`）；动作「检查状态」（Mac 上还查扩展有没有设上游），以及 Windows / Linux 上的启动、关闭、重启。
- `launcher/menu.mjs`：首页回答「能不能玩 / 哪里不对 / 下一步」，`problems()` 每条带修复按键（`block` = 不修不能玩）；首页 回车 / 1 手机 / 2 重启代理 / 3 检查状态 / 4 更多 >。「手机」是单独一页（连接码、二维码、开关、同步、合盖不睡）；「更多」分三组：账号和维护（登录、修复依赖、日志、开机启动、关闭代理）、手机上的 TauriTavern（TT 守护 >、合盖不睡）、其他（生图 >、导入、提示词拆分），返回回到上一层。每个动作做完「按回车回到菜单」，窗口不自动关。只有 Mac 的判断统一走 `core.mjs` 的 `macOnly()`。
- `launcher/phone.mjs`（只 Mac）：同步手机 = 看两边 → 预览（自动 / 要你选 / 跳过）→ 你选 → 关 TT → `phone_sync.py --choices` → 再 `--plan-json` 核对 → 结果 → 重新打开 TT。计划和执行都在 `phone_sync.py`（`--plan-json`、`--choices`、`--result-json`）：TT 守护恢复中拒绝、恢复没做完要确认、写手机前 `ui.sh backup tt` 快照、被覆盖的先备份、从不删文件；不带 `--choices`（手机遥控同步、`--auto`）按安全默认。TT 守护菜单：版本对 `update.json`（只提示去 KernelSU 更新）、`pc/pull-backups.sh`、`pc/install-mac.sh [--uninstall]`、`ui.sh list-backups` / `ui.sh restore`。从不 `adb install`、从不 `adb kill-server`（TT 守护的定时任务每分钟在用 adb）。
- 关程序只按 PID：端口上监听的进程，再确认是我们的（工作目录在程序目录里、`data/logs/*.pid` 记下的、或代理 `/status` 报的 `pid`），从不按名字。重启前问代理 `busy`，在写回复就拒绝。
- 留在各系统脚本里的：Mac 的手机模式、合盖、守护、Mac App 在不在跑、adb 设备（`mac/menu-status.zsh`）、连手机（`mac/phone-connect.zsh`）；Mac 的启动 / 关闭 / 重启（要连带手机模式守护和合盖）；登录、生图。Windows 的 `claude-max.ps1` 只剩登录、修复依赖、开机启动、日志；Termux 的代理在 Debian 子系统里，启停仍由 `termux/claude-max.sh` 做。别的系统上没有的显示「只支持 Mac」。

## 面板

`src/panel/index.js` 只做启动：查重复加载、用 `import()`（相对 `import.meta.url`）载入模块、启动。面板全是 ES 模块，不静态导入酒馆模块。

```
index.js      启动入口（manifest 指向它）：必需模块 core/boot.js；features/ 里每个功能各自 try/catch 载入
core/         底座，所有 tab 和功能共用
  store.js         状态仓库 createStore（纯）+ 面板的 store：proxyState / proxyOnline / status / quota / stats / backend / glance / nextEffort / pulse
  live.js          唯一去问代理的地方：状态、额度、用量、后端、20 秒心跳、refreshAll；结果写进 store
  capabilities.js  平台和连接判断集中在这（纯函数）：IS_TAURI / COARSE / 手机类设备 / 省电显示 / 只能直连代理 / 云端酒馆 / 连的是本代理还是直连 Claude
  settings.js      默认设置、getSettings、saveSettingsDebounced；键名是存在酒馆里的，不能改
  notify.js        通知：酒馆的 toast
  libs.js          src/shared/ 的可选辅助（体检、世界书、角色卡、预设推荐、云端检测、来源）；缺哪个只影响对应功能
  registry.js      功能注册表 F：F.checkup.runCheckup()；功能没载入时是空操作
  inject.js        每条请求注入 claude_subscription 设置（CHAT_COMPLETION_SETTINGS_READY）+ 发送前检查
  events.js        面板监听的全部酒馆事件，注册顺序即运行顺序
  tabs.js          分页表 TABS 和存过的分页键迁移 resolveTab（纯函数：'mac' → 'other'）
  boot.js          启动顺序；connect-help.js 未连接卡片按情况说什么（纯函数）；proxy.js 请求代理；connection.js 连接和模型名；dom.js 小控件；st.js / replies.js 杂项
shell.js      抽屉、顶部一句话、状态条、分页条、一键连接、重建面板
tabs/         推理 reason · 状态 status · 设置 settings · 其他 other（Mac 遥控 mac.js、体检（实验）check.js 是其中的折叠区）；各自建 DOM，订阅 store 里自己要画的键
features/     可选功能：reply-keeper 防丢回复 · checkup 最新回复检查与体检（实验） · card-audit 角色卡检查 · lore-cache 世界书常驻 · backend-form 代理后端表单
              · perf-diag 性能诊断 · quiet-render 省电显示 · compact-buttons 脚本按钮并排 · presets 预设推荐 / byModel
              · models 模型切换和来源处理 · debug-request 查看请求 · image-score /图分 · gen-progress 生成进度（状态栏） · turn-notice 回复后提示
```

数据流：`live.js` 拉数据 → `store.set()` → 订阅者按 id 找 DOM 重画（订阅只在启动时做一次，重建面板不用重新订阅）。`refreshAll()` = 给 `pulse` 加一，本地重画（连接提示、缓存卡、世界书、体检、角色卡检查）都听它，再启动状态和额度 / 用量的请求。新增一个 tab 或功能：写一个模块导出 `init()`（订阅）和 `buildXxxTab()`，在 `index.js` 的 `FEATURES` 里登记（tab 在 `shell.js` 里加）。

新文件加进 `src/proxy/plugin.js` 的 `UI_EXTENSION_FILES`（`test/panel-files.test.js` 会查漏）。

## 两种安装方式都要能用

- **扩展安装**：酒馆「安装扩展」填仓库地址 → 整个仓库克隆到 third-party，酒馆按 `manifest.json` 加载 `src/panel/`。
- **服务器插件**：`plugins/` 下克隆 → 酒馆加载 `package.json` 的 `main`；插件启动时把面板用到的文件（`UI_EXTENSION_FILES`）复制到 third-party，已经用扩展安装过就跳过。
- 挪动面板文件时，两处都要跟着改：`manifest.json` 和 `src/proxy/plugin.js` 的 `UI_EXTENSION_FILES`。

## 约定

- 路径一律从 `src/proxy/paths.js` 取，不在各文件里数 `..`。
- 面板不静态导入酒馆模块（只用 `SillyTavern.getContext()`），所以装在哪个位置都能用；`src/shared/` 和 `features/` 用动态 `import()` 加载，缺了或加载失败只影响对应功能。
- 本机文件（`launcher/*.local`、`data/`）不进提交，门控会拦。
