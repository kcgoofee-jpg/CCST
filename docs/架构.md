# 架构

## 运行时

```
酒馆 / TauriTavern ──(发消息)──▶ 面板 src/panel（改请求参数、检查、生成进度）
   （浏览器 / App）                 │
                                    ▼
                                 代理 src/proxy（本机 :8901，OpenAI 兼容）
                                    │  会话续接、缓存排布、防丢回复、额度 / 用量
                                    ▼
                         官方 Claude Code / Agent SDK（后端见 backend-config.js）
                                    ▼
                         Anthropic（订阅）

组件的摆法：
  原版酒馆      浏览器(酒馆+面板) ─▶ SillyTavern ─(服务器插件 = 代理，installer/ 一键安装)─▶ Claude
  单独运行代理  酒馆 / TauriTavern(面板) ─▶ 同一台电脑上的独立代理(npm start) ─▶ Claude
```

## 目录

| 路径 | 是什么 | 在哪运行 |
| --- | --- | --- |
| `manifest.json` | 酒馆扩展清单（酒馆要求放根目录），指向 `src/panel/` | — |
| `package.json` | 版本号唯一来源；`main` 指向 `src/proxy/plugin.js`（酒馆服务器插件入口）| — |
| `server.js` | 独立运行代理的入口（`npm start`）。只有一行，转到 `src/proxy/server.js`，留在根目录让老的启动方式不失效 | Node |
| `src/panel/` | 面板：`index.js`（启动入口）、`core/`、`shell.js`、`tabs/`、`features/`、`style.css`，见下面「面板」| 浏览器 / App WebView |
| `src/proxy/` | 代理，分层见下面「代理分层」；`plugin.js`（酒馆插件入口）、`server.js`（独立入口）；`paths.js` 统一给出仓库根目录和 `data/` | Node |
| `src/shared/` | 面板和代理 / 开发脚本共用的纯函数：最新回复检查、预设推荐、云端酒馆检测、Claude 模型名、API 价格表 | 两边 |
| `bin/claude-cli.js` | 调用随附的 Claude Code（登录、查登录状态：`npm run login`）| Node |
| `installer/` | 一键安装器（原版酒馆）：`CCST安装.command`（Mac，由根目录的 `install-plugin-mac.sh` 在终端里下载运行，不带「来自网络」标记所以不会被 macOS 15 拦；`CCST-mac.zip` 只留给旧版面板的下载链接）、`CCST安装.bat` + `ccst-install.ps1`（Windows）；把代理装成酒馆服务器插件。环境变量 `CCST_BRANCH` 可指定分支 | 用户电脑 |
| `test/` | 单元测试：`*.test.js`（`npm test`）| 开发 / CI |
| `scripts/` | 开发脚本：门控 `gate.sh`、版本 `version.mjs` | 开发 |
| `docs/` | 设计文档（定位、架构、版本规范）和 `assets/` | — |
| `data/` | 运行时数据：用量、CLI 环境信息固定（`cli-context.json`）。本机专用，不进仓库 | — |

## 代理分层

`src/proxy/` 从上到下四层，依赖只往下：

- `api/`：对外的接口。`routes.js` 是**唯一的路由表**（每条：方法、独立监听路径、酒馆插件路径、处理函数、CORS / Origin 规则），`registerRoutes(router, 'standalone' | 'plugin')` 把它挂到两个入口上——独立监听（`listener.js`，`/v1/*`）和酒馆插件（`plugin.js`，`/api/plugins/claude-subscription/*`，只挂面板同源要读的几条）。加接口只改路由表。`guards.js` 是 Host / Origin / 只给本机 / CORS；`status.js` 是 `/status`。
- `core/`：对话主线：`chat.js`（请求 → SDK）、`sse.js`、`stops.js`、`system-prompt.js`、`sdk-loader.js`、`env.js`（子进程环境）、`models.js`、`transcript.js`。
- `features/`：会话与缓存布局（`session-store`、`jsonl-entries`、`turn-capture`、`system-placement`、`lore-tail`、`cache-diag`）和其余功能（`reply-keeper`、`usage-stats`、`oauth`（额度）、`last-request`（最近一次请求，供「查看」）、`diag-log` / `diag-report` / `wire-tap`（诊断）、`errors-zh`、`settings`）。
- `platform/`：`control.js` 数正在写的回复（`countInFlight` / `busyCount`）。

## 面板

`src/panel/index.js` 只做启动：查重复加载、用 `import()`（相对 `import.meta.url`）载入模块、启动。面板全是 ES 模块，不静态导入酒馆模块。

```
index.js      启动入口（manifest 指向它）：必需模块 core/boot.js；features/ 里每个功能各自 try/catch 载入
core/         底座，所有 tab 和功能共用
  store.js         状态仓库 createStore（纯）+ 面板的 store：proxyState / proxyOnline / status / quota / stats / backend / glance / nextEffort / pulse
  live.js          唯一去问代理的地方：状态、额度、用量、后端、20 秒心跳、refreshAll；结果写进 store
  capabilities.js  平台和连接判断集中在这（纯函数）：IS_TAURI / COARSE / 只能直连代理 / 云端酒馆 / 连的是不是本代理
  settings.js      默认设置、getSettings、saveSettingsDebounced；键名是存在酒馆里的，不能改
  notify.js        通知：酒馆的 toast
  libs.js          src/shared/ 的可选辅助（最新回复检查、世界书、预设推荐、云端检测、模型名）；缺哪个只影响对应功能
  registry.js      功能注册表 F：F.checkup.renderLatestFlags()；功能没载入时是空操作
  inject.js        每条请求注入 claude_subscription 设置（CHAT_COMPLETION_SETTINGS_READY）+ 发送前检查
  events.js        面板监听的全部酒馆事件，注册顺序即运行顺序
  tabs.js          分页表 TABS 和存过的分页键迁移 resolveTab（纯函数：'mac' → 'other'）
  boot.js          启动顺序；connect-help.js 未连接卡片按情况说什么（纯函数）；proxy.js 请求代理；connection.js 连接和模型名；dom.js 小控件；st.js / replies.js 杂项
shell.js      抽屉、顶部一句话、状态条、分页条、一键连接、重建面板
tabs/         聊天 chat · 状态 status · 设置 settings；各自建 DOM，订阅 store 里自己要画的键
features/     可选功能：reply-keeper 防丢回复 · checkup 最新回复检查 · lore-cache 世界书常驻
              · presets 预设推荐 / byModel · models 模型切换 · debug-request 查看请求 · gen-progress 生成进度（状态栏） · turn-notice 回复后提示
```

数据流：`live.js` 拉数据 → `store.set()` → 订阅者按 id 找 DOM 重画（订阅只在启动时做一次，重建面板不用重新订阅）。`refreshAll()` = 给 `pulse` 加一，本地重画（连接提示、缓存卡、世界书、最新回复检查）都听它，再启动状态和额度 / 用量的请求。新增一个 tab 或功能：写一个模块导出 `init()`（订阅）和 `buildXxxTab()`，在 `index.js` 的 `FEATURES` 里登记（tab 在 `shell.js` 里加）。

新文件加进 `src/proxy/plugin.js` 的 `UI_EXTENSION_FILES`（`test/panel-files.test.js` 会查漏）。

## 两种安装方式都要能用

- **扩展安装**：酒馆「安装扩展」填仓库地址 → 整个仓库克隆到 third-party，酒馆按 `manifest.json` 加载 `src/panel/`。
- **服务器插件**：`plugins/` 下克隆 → 酒馆加载 `package.json` 的 `main`；插件启动时把面板用到的文件（`UI_EXTENSION_FILES`）复制到 third-party，已经用扩展安装过就跳过。
- 挪动面板文件时，两处都要跟着改：`manifest.json` 和 `src/proxy/plugin.js` 的 `UI_EXTENSION_FILES`。

## 约定

- 路径一律从 `src/proxy/paths.js` 取，不在各文件里数 `..`。
- 面板不静态导入酒馆模块（只用 `SillyTavern.getContext()`），所以装在哪个位置都能用；`src/shared/` 和 `features/` 用动态 `import()` 加载，缺了或加载失败只影响对应功能。
- 本机文件（`data/`、`*.local`）不进提交，门控会拦。
